# Roadmap: Namespace / AppExchange — Not Applicable

Apex's plan for a namespaced AppExchange listing (registering the `XFTY`
namespace, dropping the `XFTY_` class prefix, promoting the framework out of
`@IsTest`) is a Salesforce distribution concept with no C# equivalent.

This port's distribution question, if and when it has one, is ordinary NuGet
packaging — see [contribute/packaging.md](../contribute/packaging.md) for
where that stands today (not yet published).
